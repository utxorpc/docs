# Playground

Welcome to the UTxORPC playground, a fully interactive web interface where you can experiment with every RPC endpoint provided by UTxORPC specifications. Use this tool to explore query, sync, submit, and watch capabilities in real time without leaving your browser.

With the playground, you can craft custom requests, adjust parameters on the fly, and immediately view the server’s responses. Whether you want to read ledger state, fetch blocks, submit transactions, or monitor mempool activity, this interface brings all endpoints together in a single, convenient workspace.
