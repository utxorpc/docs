<a name="utxorpc-v1beta-query-UtxoPredicate"></a>

### UtxoPredicate
Represents a simple utxo predicate that can composed to create more complex ones

| Field | Type | Label | Description |
| ----- | ---- | ----- | ----------- |
| match | [AnyUtxoPattern](#utxorpc-v1beta-query-AnyUtxoPattern) | optional | Predicate is true if tx exhibits pattern. |
| not | [UtxoPredicate](#utxorpc-v1beta-query-UtxoPredicate) | repeated | Predicate is true if tx doesn&#39;t exhibit pattern. |
| all_of | [UtxoPredicate](#utxorpc-v1beta-query-UtxoPredicate) | repeated | Predicate is true if utxo exhibits all of the patterns. |
| any_of | [UtxoPredicate](#utxorpc-v1beta-query-UtxoPredicate) | repeated | Predicate is true if utxo exhibits any of the patterns. |

 

 

 

<a name="utxorpc-v1beta-query-QueryService"></a>

### QueryService
Service definition for querying the state of the chain.

| Method Name | Request Type | Response Type | Description |
| ----------- | ------------ | ------------- | ------------|
| ReadParams | [ReadParamsRequest](#utxorpc-v1beta-query-ReadParamsRequest) | [ReadParamsResponse](#utxorpc-v1beta-query-ReadParamsResponse) | Get overall chain state. |
| ReadUtxos | [ReadUtxosRequest](#utxorpc-v1beta-query-ReadUtxosRequest) | [ReadUtxosResponse](#utxorpc-v1beta-query-ReadUtxosResponse) | Read specific UTxOs by reference. |
| SearchUtxos | [SearchUtxosRequest](#utxorpc-v1beta-query-SearchUtxosRequest) | [SearchUtxosResponse](#utxorpc-v1beta-query-SearchUtxosResponse) | Search for UTxO based on a pattern. |
| ReadData | [ReadDataRequest](#utxorpc-v1beta-query-ReadDataRequest) | [ReadDataResponse](#utxorpc-v1beta-query-ReadDataResponse) | Read specific datum by hash |
| ReadTx | [ReadTxRequest](#utxorpc-v1beta-query-ReadTxRequest) | [ReadTxResponse](#utxorpc-v1beta-query-ReadTxResponse) | Get Txs by chain-specific criteria. |
| ReadGenesis | [ReadGenesisRequest](#utxorpc-v1beta-query-ReadGenesisRequest) | [ReadGenesisResponse](#utxorpc-v1beta-query-ReadGenesisResponse) | Get the genesis configuration |
| ReadEraSummary | [ReadEraSummaryRequest](#utxorpc-v1beta-query-ReadEraSummaryRequest) | [ReadEraSummaryResponse](#utxorpc-v1beta-query-ReadEraSummaryResponse) | Get the chain era summary |
| ReadState | [ReadStateRequest](#utxorpc-v1beta-query-ReadStateRequest) | [ReadStateResponse](#utxorpc-v1beta-query-ReadStateResponse) | Run a chain-specific ledger-state query (e.g. stake pool distribution). |
