# .NET SDK

Utxorpc.Sdk is the .NET client for UTxO RPC. One `UtxorpcClient` gives you the Sync, Query, Submit and Watch modules of both `v1beta` and `v1alpha` over one connection, with short methods that take plain .NET values. Calls return the Spec's messages; chain-event streams return the SDK's own event types.

## Prerequisites

- **.NET 11** SDK or later.

## Installation

Start with `dotnet new console` (or `dotnet new web` for section 5), then install the SDK:

```bash
dotnet add package Utxorpc.Sdk --version 2.0.0-alpha
```

## Usage

<Callout type="note">
    The following code samples assume that the UTxORPC node is running locally on `localhost:50051`. If your node is hosted remotely or on a different server, replace `"http://localhost:50051"` with the appropriate server URL and port for your environment. 
    
    For more details on configuring your node, refer to the [UTxORPC Ecosystem Servers Documentation](/servers).
</Callout>

The samples are taken from the [example programs](https://github.com/utxorpc/dotnet-sdk/tree/main/examples) in the SDK's repository, which you can run as they are.

### 1. Connect

Start a console program with these lines. Create one client and keep it for the life of your program; headers, such as a provider's API key, go on every call. The `dmtr-api-key` header shown here is Demeter's. Each of the next three samples continues this program.

```csharp
using System.Diagnostics;
using Google.Protobuf.WellKnownTypes;
using Utxorpc.Sdk;
using Utxorpc.Sdk.V1Beta;
using Beta = Utxorpc.V1Beta;

string url = Environment.GetEnvironmentVariable("UTXORPC_URL") ?? "http://localhost:50051";
string? apiKey = Environment.GetEnvironmentVariable("DMTR_API_KEY");
Dictionary<string, string>? headers = apiKey is null ? null : new() { ["dmtr-api-key"] = apiKey };
using UtxorpcClient u5c = new(url, headers);

// Ctrl+C cancels the call in flight.
using CancellationTokenSource cancellation = new();
Console.CancelKeyPress += (_, e) =>
{
    e.Cancel = true;
    cancellation.Cancel();
};
CancellationToken ct = cancellation.Token;
```

### 2. Follow the tip

Read the tip, then follow the chain from there. Each event is one of three cases, and the compiler warns when a switch expression misses one; the explicit `null` arm preserves that check.

```csharp
try
{
    Beta.Sync.BlockRef tip = (await u5c.V1Beta.Sync.ReadTipAsync(ct)).Tip;
    Console.WriteLine($"Tip: slot {tip.Slot}, hash {Convert.ToHexString(tip.Hash.Span)}");
    BlockPoint point = new(tip.Slot, tip.Hash.Memory);
    await foreach (FollowTipEvent e in u5c.V1Beta.Sync.FollowTipAsync(point, cancellationToken: ct))
    {
        Console.WriteLine(e switch
        {
            BlockApplied a => $"Apply: {a.Block.NativeBytes.Length} bytes",
            BlockUndone u => $"Undo: {u.Block.NativeBytes.Length} bytes",
            Reset r => $"Reset: slot {r.Point.Slot}",
            null => throw new UnreachableException()
        });
    }
}
catch (OperationCanceledException)
{
    Console.WriteLine("Stopped.");
}
```

### 3. Query

Read the protocol parameters, then every unspent output of an address, passed as hex on the command line. Addresses are raw bytes, and the search reads all pages for you. The mask asks only for the parameter values.

```csharp
try
{
    Beta.Cardano.PParams parameters = (await u5c.V1Beta.Query.ReadParamsAsync(
        FieldMask.FromFieldNumbers<Beta.Query.ReadParamsResponse>(Beta.Query.ReadParamsResponse.ValuesFieldNumber), ct)).Values.Cardano;
    Console.WriteLine($"Largest transaction: {parameters.MaxTxSize} bytes");
    byte[] address = Convert.FromHexString(args[0]);
    await foreach (Beta.Query.AnyUtxoData output in u5c.V1Beta.Query.SearchUtxosByAddressAsync(address, cancellationToken: ct))
    {
        Console.WriteLine($"{Convert.ToHexString(output.TxoRef.Hash.Span)}#{output.TxoRef.Index}: {output.NativeBytes.Length} bytes");
    }
}
catch (OperationCanceledException)
{
    Console.WriteLine("Stopped.");
}
```

### 4. Submit

Evaluate a transaction you signed, passed as hex on the command line, then submit it and wait until it is confirmed. Submitting spends the transaction's fee; evaluating spends nothing.

```csharp
byte[] tx = Convert.FromHexString(args[0]);
try
{
    Beta.Submit.EvalTxResponse evaluation = await u5c.V1Beta.Submit.EvalTxAsync(tx, ct);
    Console.WriteLine($"Evaluation: {evaluation.Report}");
    Beta.Submit.SubmitTxResponse submitted = await u5c.V1Beta.Submit.SubmitTxAsync(tx, ct);
    await foreach (Beta.Submit.WaitForTxResponse update in u5c.V1Beta.Submit.WaitForTxAsync(submitted.Ref.Memory, ct))
    {
        Console.WriteLine(update.Stage);
        if (update.Stage == Beta.Submit.Stage.Confirmed) break;
    }
}
catch (UtxorpcException error)
{
    string outcome = error.Kind == UtxorpcErrorKind.InvalidTx ? "Rejected" : "Failed";
    Console.WriteLine($"{outcome} ({error.Kind}): {error.Detail}");
}
catch (OperationCanceledException)
{
    Console.WriteLine("Stopped.");
}
```

### 5. Dependency injection and worker services

In a web application, register one shared client from configuration. This is a whole `Program.cs`; put the server's address under `Utxorpc:Url` in `appsettings.json`.

```csharp
using Utxorpc.Sdk;
using Beta = Utxorpc.V1Beta;

WebApplicationBuilder builder = WebApplication.CreateBuilder(args);
builder.Services.AddUtxorpcClient(o =>
{
    builder.Configuration.GetSection("Utxorpc").Bind(o);
    // Set DMTR_API_KEY in the environment for a hosted server; keep keys out of files.
    if (builder.Configuration["DMTR_API_KEY"] is { } apiKey) o.Headers["dmtr-api-key"] = apiKey;
});
builder.Services.AddHealthChecks().AddCheck<UtxorpcHealthCheck>("utxorpc", timeout: TimeSpan.FromSeconds(5));
WebApplication app = builder.Build();
app.MapHealthChecks("/health");

app.MapGet("/tip", async (UtxorpcClient u5c, CancellationToken ct) =>
{
    Beta.Sync.BlockRef tip = (await u5c.V1Beta.Sync.ReadTipAsync(ct)).Tip;
    return Results.Ok(new { tip.Slot, Hash = Convert.ToHexString(tip.Hash.Span) });
});

app.Run();
```
