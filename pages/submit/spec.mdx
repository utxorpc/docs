| ----- | ---- | ----- | ----------- |

<a name="utxorpc-v1beta-submit-Stage"></a>

### Stage
Enum representing the various stages of a transaction&#39;s lifecycle.

| Name | Number | Description |
| ---- | ------ | ----------- |
| STAGE_UNSPECIFIED | 0 | Unspecified stage. |
| STAGE_ACKNOWLEDGED | 1 | Transaction has been acknowledged by the node. |
| STAGE_MEMPOOL | 2 | Transaction is in the mempool. |
| STAGE_NETWORK | 3 | Transaction has been propagated across the network. |
| STAGE_CONFIRMED | 4 | Transaction has been confirmed on the blockchain. |

 

 

<a name="utxorpc-v1beta-submit-SubmitService"></a>

### SubmitService
Service definition for submitting transactions and checking their status.

| Method Name | Request Type | Response Type | Description |
| ----------- | ------------ | ------------- | ------------|
| EvalTx | [EvalTxRequest](#utxorpc-v1beta-submit-EvalTxRequest) | [EvalTxResponse](#utxorpc-v1beta-submit-EvalTxResponse) | Evaluates a transaction without submitting it. |
| SubmitTx | [SubmitTxRequest](#utxorpc-v1beta-submit-SubmitTxRequest) | [SubmitTxResponse](#utxorpc-v1beta-submit-SubmitTxResponse) | Submit transactions to the blockchain. |
| WaitForTx | [WaitForTxRequest](#utxorpc-v1beta-submit-WaitForTxRequest) | [WaitForTxResponse](#utxorpc-v1beta-submit-WaitForTxResponse) stream | Wait for transactions to reach a certain stage and stream the updates. |
| ReadMempool | [ReadMempoolRequest](#utxorpc-v1beta-submit-ReadMempoolRequest) | [ReadMempoolResponse](#utxorpc-v1beta-submit-ReadMempoolResponse) | Returns a point-in-time snapshot of the mempool. |
| WatchMempool | [WatchMempoolRequest](#utxorpc-v1beta-submit-WatchMempoolRequest) | [WatchMempoolResponse](#utxorpc-v1beta-submit-WatchMempoolResponse) stream | Stream transactions from the mempool matching the specified predicates. |
