<a name="utxorpc-v1beta-cardano-BigInt"></a>

### BigInt
Represents a big integer for Plutus data in Cardano.
The representation here follows CBOR specification for bignums:
https://www.rfc-editor.org/rfc/rfc8949.html#name-bignums section 3.4.3.

| Field | Type | Label | Description |
| ----- | ---- | ----- | ----------- |
| int | int64 |  | Stores value fitting within int64 range |
| big_u_int | bytes |  | Stores unsigned value exceeding int64 range |
| big_n_int | bytes |  | Stores negative value `n` exceeding int64 range as `-1 - n` |

### EvalReport
A single evaluation report entry, used for both script errors and execution
traces. The purpose and index fields identify which redeemer produced the
entry, allowing the client to correlate errors and traces with specific
script executions.

| Field | Type | Label | Description |
| ----- | ---- | ----- | ----------- |
| msg | string |  | Human-readable message. |
| purpose | [RedeemerPurpose](#utxorpc-v1beta-cardano-RedeemerPurpose) |  | Purpose of the redeemer that produced this entry. |
| index | uint32 |  | 0-based index of the redeemer within its purpose. |
